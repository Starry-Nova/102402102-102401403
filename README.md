# 拾星 · 第 8 阶段：归还状态

## 运行

解压后使用 Chrome 打开 index.html，无需安装依赖或服务器。保留 assets 相对路径。

## 本阶段新增

发布者权限、交接对象、状态联动。

## 验收

只有发布者可确认；选择对方后变为已找回/已归还；本阶段还不能送玫瑰。

## 累计能力

1. 入口、脚本、样式与最小运行说明
2. 浅色星空主题、北斗导航、页面容器
3. 校园夜景地图、五条示例信息、照片便签、四色状态星
4. 关键词、类别、地点、日期、状态组合筛选
5. 便签到详情、物品特征、发布者和核对提示
6. 三个账号切换、头像与各自我的发布
7. 表单、错误提示、照片上传和地图选址
8. 本地持久化、发布成功页、跨页草稿保留
9. 模拟短信、绑定、校园认证、待审及通过拒绝
10. 认证后显示号码、复制与失败回退
11. 发布者权限、交接对象、状态联动

## 限制

数据只保存到当前浏览器，不跨设备同步。
